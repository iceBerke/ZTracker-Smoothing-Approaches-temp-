  READ THE W_smooth COLUMN WITH CARE. It is very nearly k-INVARIANT and is therefore
  NOT good evidence that the window is well determined. The requirement is
  W >= (2*k^2*sigma^2/Gamma)^(1/alpha), so k enters each method as k^(2/alpha). When every method
  has the same alpha this cancels EXACTLY out of any ratio between them; when they differ it
  cancels only approximately, leaving a weak residual dependence through the spread in alpha.
  Before the 1/alpha correction the cancellation was exact and the spread was identical at every
  k to four decimals. It is still far too weak to treat agreement here as evidence about k.
  Agreement here is strong evidence about sigma and alpha, which are measured independently by
  each method. It is structurally void as evidence about the smoothing window, because no
  value of k could make these methods disagree. The absolute window still scales as k^2 and
  k is still chosen by hand -- see 'HOW THIS SMOOTHING WINDOW WAS SET' in each method's
